## 개요
- 목적: Google Sheets에 가계부 항목을 기록하는 앱
- 구현 방식:
  1. Node + Express + Google OAuth 브라우저 앱
  2. Google Apps Script 웹앱

## 현재 구현 상태 요약
### Node 웹앱
- Google Identity Services 기반 로그인
- 편집 가능한 Google Spreadsheet 목록 조회
- Spreadsheet 내 시트 탭 목록 조회
- 날짜/카테고리/금액/비고 입력
- 선택한 시트에 A:E 열 순서로 append
- `/api/config`, `/healthz` 제공
- 정적 프론트엔드(`public/index.html`, `public/app.js`, `public/styles.css`) 기반

### Apps Script 버전
- `submitEntry(formData)`로 시트에 appendRow
- `setupSheet()`로 헤더 초기화
- Script Properties에 Spreadsheet/시트 설정 저장 가능

## 코드 구조 관찰
- `server.js`: 정적 파일 제공 + 환경설정 전달용 API
- `public/app.js`: 인증, Drive API 호출, Sheets API 호출, UI 상태 관리, 폼 제출이 한 파일에 집중
- `apps-script/`: 대체 배포 방식 제공

## 개선 포인트
1. 테스트 부재
   - 자동화 테스트가 없어 기능 변경 안정성이 낮음
2. 프론트엔드 단일 파일 집중
   - 인증, API, UI, 상태 관리가 `public/app.js` 하나에 몰려 있음
3. 서버 레이어가 매우 얇음
   - 핵심 로직이 브라우저에 치우쳐 있음
4. UX 개선 여지
   - 최근 선택 기억, 카테고리 프리셋, 날짜 기본값 등 없음
5. 의존성 점검 필요
   - `googleapis` 패키지는 현재 Node 런타임 코드에서 직접 사용되지 않음

## 이번 작업 목표
- 새로운 브랜치에서 UI를 2단계로 분리
  1. 첫 페이지: Google 인증 + Spreadsheet/시트 선택
  2. 두번째 페이지: 선택한 파일/시트에 가계부 데이터 입력 및 저장
- 선택 정보는 두 페이지 사이에서 유지되어야 함
- 가능하면 테스트를 먼저 추가한 뒤 구현 진행
